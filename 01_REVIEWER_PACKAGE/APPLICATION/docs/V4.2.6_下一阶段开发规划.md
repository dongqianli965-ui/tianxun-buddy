# V4.2.6 下一阶段开发规划

1. 由真实授权人员逐页完成 10 个 OCR 复核任务，记录修改、提交版本、独立复核决定和资质登记；人工证据齐全前保持 BLOCKED。
2. 补齐第二地域及本期正式价格来源，建立跨地域正例、重复记录处理和专业签认验收。
3. 在隔离 PostgreSQL PoC 上完成 schema、迁移、回滚、重复执行和并发验证；通过后再单独评审生产切换。
4. 将 OCR 缓存键从请求页范围解耦为来源内容/页级稳定键，并补充跨页范围重复执行测试。
5. 建立独立算量输入、规则、复核和误差基准，完成工程精度 E 验收后再讨论正式组价闭环。
6. 保持 WRITE/REVIEW 分离、owner-claim 不自动补齐、BLOCKED 不自动升级 VERIFIED。

下一阶段按业务依赖分批验收：先完成人工 OCR 校对和来源授权补证，再补第二地域与本期价格；随后用可独立复算的真实项目建立算量底稿、误差基准及复核记录；正式授权定额、费率和适用版本齐备后才开展定额匹配、费用计算与正式成果输出。每一步分别保留输入文件哈希、规则版本、修改记录和实际验收人。

PostgreSQL 保留为隔离 PoC 路线。已有完整回归覆盖到的迁移测试，只说明测试范围内的行为通过；生产切换还需真实业务负载、备份恢复、演练回滚及独立切换决策。本轮没有切换生产数据库，也不把此项当成下一阶段的默认先决条件。
