## 已验证

- OCR 技术工作流：导入、页图/原件锚定、草稿提交、版本绑定、审批/退回、审计链检测。
- 真实材料样本查询：10989 条带来源与文件 SHA256 的记录，可拒绝歧义解析。
- B_REFERENCE 清单：148 行逐字段导入导出一致。
- 安全交付：两个 profile 包经过 CRC、逐文件 SHA256 和敏感值扫描。

## 明确限制

- 真实人工 OCR 复核为 0，专业签认 0；10 个逐页任务状态为 `READY_FOR_HUMAN_REVIEW`，`human_review_status=BLOCKED`。
- 当前只有 `410100-INNER-4RING` 一个地域；跨地域正例 `BLOCKED`。
- 当前正式价格依据和专业签认缺失，正式当前价格 `BLOCKED`。
- B_REFERENCE 不是独立算量；工程精度验收 `BLOCKED`。
- 定额组价、正式工程造价闭环、生产 PostgreSQL 迁移均 `BLOCKED`。
- OCR 执行缓存仍按请求页范围参与键计算，不能宣称不同页范围绝不重复执行；SQLite 文件所有者可绕过触发器保护。
